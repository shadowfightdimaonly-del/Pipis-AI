Где взять ключ?
  1. Открой aistudio.google.com/apikey (нужен аккаунт Google).
  2. Нажми «Create API key» и выбери любой проект.
  3. Скопируй ключ (начинается с AIza…) и вставь в поле выше.
  4. Сохрани настройки. Ключ остаётся только на этом устройстве.

Все запросы пойдут через этот адрес. API-ключ тоже проходит через прокси, поэтому используй только свой.
